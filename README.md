# CS 350: Emerging Systems Architectures and Technologies

## Project Reflection

### 1. Summarize the project and what problem it was solving.

For this course, I worked with a Raspberry Pi to learn how hardware and software communicate with each other. Throughout the course, I completed several milestones that involved controlling LED lights, using GPIO pins, working with pushbuttons, and displaying information on a 16x2 LCD screen. For my final project, I developed a smart thermostat prototype that uses a temperature sensor to monitor room temperature and LED lights to indicate heating and cooling modes. The purpose of this project was to demonstrate how embedded systems can be used to automate everyday devices and how software can control hardware components.

### 2. What did you do particularly well?

I think one thing I did particularly well was troubleshooting problems and finding ways to get my hardware and software working together. I took my time checking the wiring connections, reviewing my Python code, and testing individual components whenever something wasn't working correctly. I also became more comfortable using the Raspberry Pi and understanding how GPIO pins communicate with different hardware components.

### 3. Where could you improve?

One area where I could improve is planning my circuit layout and organizing my code before starting a project. There were times when I spent more time troubleshooting because my breadboard was different from the examples provided in the lab instructions. I also ran into issues with incorrect wiring and coding errors that could have been avoided with better planning. Moving forward, I want to spend more time reviewing the hardware requirements and testing smaller sections of my code before putting everything together.

### 4. What tools and/or resources are you adding to your support network?

Throughout this course, I became more familiar with using Python, Raspberry Pi documentation, course lab guides, and online programming resources. I also used AI tools to help understand error messages and troubleshoot issues with my code. These resources helped me learn more about embedded systems and how to solve problems independently. I plan to continue using these tools in future programming courses and personal projects.

### 5. What skills from this project will be particularly transferable to other projects and/or course work?

Some of the most valuable skills I gained from this course were Python programming, hardware troubleshooting, debugging, and understanding how software interacts with physical components. I also learned how to work with GPIO pins, sensors, and LCD displays. These skills can be useful in future computer science courses, especially when working with automation, Internet of Things (IoT) devices, and other embedded systems. Learning how to break down complicated problems into smaller tasks is another skill that I can apply to almost any programming project.

### 6. How did you make this project maintainable, readable, and adaptable?

I focused on keeping my Python code organized and easy to understand by using meaningful variable names, comments, and separate functions for different tasks. I also tried to follow the coding examples and structure provided in the course materials. By keeping the code organized, it becomes easier to identify errors, make changes, or add new features later. For example, the smart thermostat prototype could eventually be expanded to include Wi-Fi connectivity, remote monitoring, or additional sensors without having to completely redesign the program.

## Conclusion

Overall, CS 350 gave me a better understanding of how embedded systems work and how important it is for hardware and software to communicate properly.
